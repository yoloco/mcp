# Contributing

This repository holds the public documentation of the hosted Yoloco MCP server: the tool
catalogue, setup guides, example prompts and the registry manifest. The server itself is
operated by Yoloco and is not in this repository.

## What is welcome

* Corrections and clarifications in `README.md`, `TOOLS.md`, `examples/` and `llms.txt`.
* Setup instructions for an MCP client that is not covered yet (with the client version you tested).
* Example prompts that worked well for you, in `examples/PROMPTS.md`.

## How

1. Open an issue first for anything beyond a typo, so we can agree on the change.
2. Fork, branch from `main`, keep one topic per pull request.
3. Write in English; keep the tone of the existing files.
4. Tool names, prices and limits come from the server: if `TOOLS.md` disagrees with what the
   server answers, report it as a bug rather than editing the table by hand.

Security issues go to security@yoloco.io, never to a public issue (see `SECURITY.md`).
